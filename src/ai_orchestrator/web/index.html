No document has been published. Run make seed-docs.
A document that was sent is not a document that was read. The tile counts acknowledgements, not sends, because emailed-to-everybody and read-by-nobody is the most common state of a controlled document set in construction — and it is invisible without a column somebody is required to fill in. Expiry is not retention: a permit stops being true long before it may be destroyed, and the two dates are separate columns for that reason.
